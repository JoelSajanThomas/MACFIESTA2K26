# Official assets folder

Place official MacFiesta images here when replacing placeholders.

Update paths in `frontend/src/utils/assets.js` and `frontend/src/utils/brand.js`.

Example structure:

```
official/
  hero.jpg
  about.jpg
  cta.jpg
  event-default.jpg
  sponsors/
    partner-one.png
```

Do not commit copyrighted assets from the old website unless you have official permission.
