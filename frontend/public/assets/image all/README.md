# image all

Single public media tree for MacFiesta (no duplicate copies outside this folder).

## Layout

- `official/` — production site media
- `ref-ui/` — cinematic Marvel × DC UI pack
- `original/` — original universe emblems / backgrounds / silhouettes

Fonts stay at `/Fonts/` (not duplicated here).

`MANIFEST.txt` lists every file path relative to this folder.

Public URLs: `/assets/image all/<path>`
